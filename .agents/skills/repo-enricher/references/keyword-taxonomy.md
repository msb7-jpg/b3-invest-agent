# High-Signal Keyword & Topic Taxonomy for GitHub

This guide provides high-value keywords and GitHub repository topics categorized by domain. Use these to attract technical recruiters, engineering directors, and open-source contributors searching on GitHub or LinkedIn.

---

## 🏷️ Topic Formatting Rules
1. Must be lowercase, numbers, and hyphens (`-`).
2. Maximum 20 topics per repository.
3. Combine **Core Language** + **Domain/Role** + **Specialized Framework** + **Target Concept**.

## 🎯 High-Converting Headline Formula (350 Chars Max)

Use this formula when editing the repository description via `gh repo edit -d "..."`:

```text
[Emoji] [Primary Role/Artifact] + [Core Purpose & Domain] + [Key Tech Stack & Unique Advantage] + [Delivery Channel]
```

### Examples:
- **Financial AI Agent**:  
  `🤖 Autonomous AI Agent & Python SDK for B3 market intelligence via StatusInvest. Features CVM Material Facts monitoring, insider trading tracking, and zero-cost local LLM inference (llama.cpp) with Telegram alerts.`
- **Backend Service**:  
  `⚡ High-throughput asynchronous event ingestion engine built with FastAPI, Redis Streams, and PostgreSQL. Features real-time schema validation and Prometheus observability.`
- **Data Engineering**:  
  `📊 Production ETL data pipeline processing SEC corporate filings with DuckDB, PySpark, and Delta Lake. Automated daily anomaly detection and Slack reporting.`
